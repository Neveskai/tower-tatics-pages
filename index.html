Política de Privacidade — Tower Tactics 3D

Última atualização: 18 de setembro de 2026.

Resumo

Tower Tactics 3D não coleta, armazena, processa ou compartilha dados pessoais ou de identificação dos utilizadores. O jogo não requer conexão à internet para funcionar e não solicita nenhuma permissão de acesso a dados do dispositivo (localização, câmera, contactos, armazenamento, etc.).

Dados coletados

Nenhum. O aplicativo não possui sistema de contas, login, telemetria, analytics ou publicidade. Todo o progresso do jogador é guardado localmente no próprio dispositivo.

Compartilhamento de dados

Como nenhum dado é coletado, nenhum dado é compartilhado com terceiros.

Alterações a esta política

Caso funcionalidades futuras passem a envolver coleta de dados (ex.: sincronização em nuvem, anúncios), esta política será atualizada com antecedência e a nova versão será publicada nesta mesma página.
